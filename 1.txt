项目概述
========

项目名称：环境监测站（Environment Monitor）
程序目标：my_test
目标平台：RK3506G Linux
开发语言：C11
项目负责人：本人独立完成

当前代码确认的功能：

1. MQTT 客户端接收温度、湿度和有效状态 JSON 数据。
2. RS485 UART 上运行 Modbus RTU 主站轮询。
3. SocketCAN 接收和解析 CAN 报文。
4. LVGL 触摸屏界面显示 MQTT、Modbus、CAN 和 OTA 页面。
5. SQLite 保存有效温湿度记录。
6. HTTP 提供当前数据、设备数据、系统状态和 OTA 接口。
7. NTP 同步系统时间。
8. 应用程序 OTA 下载、SHA256 校验、原子替换和健康检查回滚。

数据流
======

MQTT 网络线程 → 温湿度共享数据 → 主线程 UI 更新 / 数据记录器

Modbus 轮询线程 → Data Bus → HTTP 设备接口

CAN 接收线程 → 信号解析 → Data Bus → HTTP 设备接口

CAN 原始帧 → 线程安全待处理缓冲区 → 主线程 UI 更新

当前没有独立的存储线程、消息队列、共享内存或进程间通信实现。

主要代码位置
============

- 程序入口：main.c
- MQTT：services/mqtt_client.c
- Modbus：services/modbus_master.c
- CAN：services/can_manager.c、hal/can_socket.c
- RS485：hal/rs485_uart.c
- 数据总线：services/data_bus.c
- SQLite：database.c
- 数据记录：services/data_recorder.c
- HTTP：web_server.c、web/
- OTA：ota_manager.c
- UI：ui/
- 构建：CMakeLists.txt

功能边界
========

- 当前 OTA 仅支持应用程序更新，不支持固件分区刷写。
- Web 历史数据随机模拟接口已删除。
- MQTT 断线期间只做记录统计，不提供断线补传。
- HTTPS、用户认证和完整数字签名校验不属于当前实现。
- 项目内没有 systemd、SysV init 或独立守护进程配置。
