1. 项目概述
项目名称：基于 RK3506G 的多协议工业边缘计算网关
核心功能：

通过 RS485 接口 轮询 Modbus RTU 从站设备，采集工业传感器/执行器数据。

通过 CAN 总线 采集车辆或工业设备实时数据。

本地 SQLite 数据库 存储所有历史数据。

LVGL 触摸屏界面 实时显示设备状态。

HTTP Server 提供数据查询与系统管理 API（浏览器远程访问）。

MQTT Client 将数据上报到本地 Mosquitto Broker（部署于 RK3506G），并能与云平台对接。

NTP 时间同步、OTA 固件升级、配置热加载 等企业级特性。

技术栈：C 语言、Linux (Buildroot/Yocto)、LVGL、libmodbus、SocketCAN、SQLite3、libmosquitto、libgpiod。

数据流：

Modbus 线程循环读从站 → 数据入队 → 存储线程写 SQLite + UI 更新 + MQTT 发布。

CAN 线程接收 SocketCAN 帧 → 数据入队 → 同上。

HTTP API 读取 SQLite 或内存缓存返回给浏览器。

触摸屏 LVGL 从共享内存/消息队列获取最新数据。

3. 硬件连接详细说明
3.1 引脚分配表 (J9 连接器)
功能	开发板引脚 J9	连接至模块	信号说明
CAN0_RX	20	SN65HVD230 的 RXD	接收 CAN 数据
CAN0_TX	21	SN65HVD230 的 TXD	发送 CAN 数据
UART3_RX	23	MAX485 的 RO	接收 RS485 数据
UART3_TX	24	MAX485 的 DI	发送 RS485 数据
RS485 方向控制	25 (UART2_RX)	MAX485 的 DE/RE (短接)	GPIO 输出，高电平=发送，低电平=接收
GND	接所有模块 GND	各模块 GND 引脚	共地
3.3V	供电	SN65HVD230 VCC	CAN 收发器供电
5V (或 3.3V)	视 MAX485 版本	MAX485 VCC	若为 5V 版本需电平转换，推荐 3.3V 模块
关键配置：

25 脚原本是 UART2_RX，必须在 设备树 中禁用 UART2，将其释放为普通 GPIO。

RS485 总线两端需加 120Ω 终端电阻，MAX485 模块上一般有预留焊接位。

SN65HVD230 CAN 收发器需在 CAN_H 和 CAN_L 之间加 120Ω 终端电阻（模块可能自带）。

3.2 其他辅助硬件
USB 转 RS-485：连接 PC，用 Modbus Poll / Slave 软件模拟主站或从站进行开发调试。

USB 转 CAN：连接 PC，用 cangaroo 或 can-utils 工具模拟 CAN 节点或监视总线。
